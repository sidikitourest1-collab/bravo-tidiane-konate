Qu'est-ce qu'une application ?

Un programme qui permet de réaliser des tâches sur un téléphone, une tablette ou un ordinateur.

Comprendre les applis

Qu'est-ce qu'un site web ?

Un ensemble de pages que l'on consulte avec un navigateur pour lire, apprendre, partager ou utiliser un service.

Découvrir le Web
